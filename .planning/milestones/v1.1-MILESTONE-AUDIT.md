| Item | Severity | Impact |

**Details:** The MSP listing page action menu has an "Impersonate" option that shows a "coming soon" toast instead of actual impersonation. This is non-blocking since:
1. Header tenant search provides impersonation
2. MSP detail page provides impersonation
3. Users can easily navigate to either alternative

**Recommendation:** Update `ui/src/app/mission-control/msps/page.tsx` lines 140-144 to use real `startImpersonation()` function (copy pattern from MSP detail page).
