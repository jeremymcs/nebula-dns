The first audit (2026-02-22T02:30:00Z) identified one critical gap:
- **DEPLOY-06 partial:** `create-secrets.sh` created `policy-svc-secrets` with only 2 keys (redis-url, clickhouse-url), but `policy-svc-deployment.yaml` expected 5 keys
- **Integration 24→26 broken:** ClickHouse credentials in orphaned `clickhouse-secrets` never referenced

**Resolution (Phase 34):**
- Added clickhouse-database, clickhouse-user, clickhouse-password to `policy-svc-secrets` in `create-secrets.sh`
- Added jq parsing of Terraform `clickhouse_endpoints` JSON map for HTTPS URL construction
- Removed orphaned `clickhouse-secrets` creation block
- All 5 keys now properly wired from Terraform → Secret → Deployment → Application
