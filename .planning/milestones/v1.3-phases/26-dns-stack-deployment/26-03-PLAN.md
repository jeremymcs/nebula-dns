**Part A: Create dnsdist ConfigMap resource (`k8s/base/dnsdist-configmap.yaml`)**

Create a NEW file `k8s/base/dnsdist-configmap.yaml` containing a ConfigMap that wraps the production dnsdist config. This is CRITICAL — the dnsdist Deployment already references `configMap: name: dnsdist-config` via volume mount, but no ConfigMap resource exists. Without this, dnsdist pods will fail to start with "ConfigMap not found" error.

```yaml
# Nebula DNS - dnsdist ConfigMap
# Copyright (c) 2026 Jeremy McSpadden <jeremy@fluxlabs.net>
apiVersion: v1
kind: ConfigMap
metadata:
  name: dnsdist-config
  namespace: nebula-dns
  labels:
    app: dnsdist
    app.kubernetes.io/name: dnsdist
    app.kubernetes.io/component: dns-frontend
data:
  dnsdist.conf: |
    <paste the FULL contents of config/dnsdist/dnsdist.prod.conf here, as updated by Task 1>
```

Read the updated `config/dnsdist/dnsdist.prod.conf` (from Task 1) and embed its entire contents as the `dnsdist.conf` data key. Use the `|` block scalar style for multi-line content. The ConfigMap key MUST be `dnsdist.conf` (matching the `subPath: dnsdist.conf` in the Deployment volume mount).

**Part B: Update dnsdist Deployment (`k8s/base/dnsdist-deployment.yaml`)**

**1. Replace AWS annotations with DigitalOcean annotations on both LoadBalancer services (dnsdist-1 and dnsdist-2):**

Remove these AWS-specific annotations from BOTH services:
```yaml
service.beta.kubernetes.io/aws-load-balancer-type: "nlb"
service.beta.kubernetes.io/aws-load-balancer-cross-zone-load-balancing-enabled: "true"
```

Add these DigitalOcean annotations to BOTH services:
```yaml
service.beta.kubernetes.io/do-loadbalancer-protocol: "tcp"
service.beta.kubernetes.io/do-loadbalancer-size-unit: "1"
service.beta.kubernetes.io/do-loadbalancer-disable-lets-encrypt-dns-records: "true"
```

Keep the existing `external-dns.alpha.kubernetes.io/hostname` annotations as-is (dns1.nebuladns.io and dns2.nebuladns.io).

**2. Add Prometheus annotations to the Deployment pod template:**

Add these annotations to the pod template metadata (after `labels`):
```yaml
annotations:
  prometheus.io/scrape: "true"
  prometheus.io/port: "8083"
  prometheus.io/path: "/metrics"
```

**3. Update the POLICY_SVC_URL env var:**

Change the value from `"http://policy-svc:80"` to `"http://policy-svc.nebula-dns.svc.cluster.local:80"` for explicit Kubernetes service discovery (avoids relying on search domain configuration).

**4. Update copyright year in the service comments** from generic to include the copyright header.

Do NOT change: Deployment replicas, strategy, security context, resource limits, health probes, volume mounts, HPA config, or ServiceAccount.

**Part C: Add dnsdist ConfigMap to kustomization (`k8s/base/kustomization.yaml`)**

Add `dnsdist-configmap.yaml` to the `resources` list in `k8s/base/kustomization.yaml`. Place it immediately before `dnsdist-deployment.yaml` so the ConfigMap is created before the Deployment that references it:


Note: `unbound-statefulset.yaml` will already be present from Plan 26-02 execution. Place `dnsdist-configmap.yaml` right before `dnsdist-deployment.yaml` for logical grouping.
