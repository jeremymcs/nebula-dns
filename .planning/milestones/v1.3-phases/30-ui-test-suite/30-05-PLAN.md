<task type="auto">
  <name>Task 1: Create flakiness report script and enhance Playwright config</name>
  <files>ui/scripts/flakiness-report.sh, ui/playwright.config.ts</files>
  <action>
    Create `ui/scripts/flakiness-report.sh` — a bash script that:
    1. Parses JUnit XML output from `ui/test-results/junit.xml` (already configured in playwright.config.ts)
    2. Counts total tests, passed, failed, and **flaky** tests. A flaky test is one that has retries recorded (Playwright marks retried tests in JUnit output with `<testcase>` entries that have `retry` attributes or duplicate test names where later runs pass)
    3. Calculates flakiness rate: `(flaky_tests / total_tests) * 100`
    4. Outputs a markdown summary table to stdout suitable for `$GITHUB_STEP_SUMMARY`
    5. Exits with code 1 if flakiness rate exceeds `FLAKY_THRESHOLD` (default 5%, configurable via env var)
    6. Lists each flaky test by name for debugging

    The script should handle edge cases:
    - No JUnit XML file found (warn and exit 0)
    - Zero tests run (warn and exit 0)
    - All tests passed with no retries (report 0% flakiness, exit 0)

    Also update `ui/playwright.config.ts` to add JSON reporter alongside existing reporters in CI mode. Change the CI reporter line to:
    ```
    reporter: process.env.CI
      ? [['html', { open: 'never' }], ['junit', { outputFile: 'test-results/junit.xml' }], ['json', { outputFile: 'test-results/results.json' }], ['github']]
      : [['html']],
    ```
    The JSON reporter provides structured test results that are easier to parse for flakiness detection than JUnit XML. The script should prefer JSON if available, fall back to JUnit XML.

    Add standard copyright header to new file. Make the script executable (`chmod +x`).
  </action>
  <verify>
    - `test -x ui/scripts/flakiness-report.sh` confirms script is executable
    - `bash ui/scripts/flakiness-report.sh` runs without error (may warn about missing JUnit file)
    - `grep 'json' ui/playwright.config.ts` confirms JSON reporter added
  </verify>
  <done>Flakiness report script exists, is executable, handles all edge cases, and Playwright config outputs JSON results in CI</done>
