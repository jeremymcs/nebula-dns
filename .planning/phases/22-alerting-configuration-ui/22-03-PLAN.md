<task type="auto">
  <name>Task 1: Create Alerting settings page</name>
  <files>admin-ui/src/app/(authenticated)/settings/alerting/page.tsx</files>
  <action>
    Create the Alerting settings page following users/page.tsx patterns.

    1. Page structure:
       - 'use client' directive
       - Copyright header
       - Import useRequireFeature from hooks/useRequireRole.ts
       - Import useAlertConfigs and mutation functions from hooks/useAlertConfigs.ts
       - Import AlertConfigCard, SlackConfigModal, PagerDutyConfigModal from components/alerting
       - Import Button, Card from components/ui
       - Import ConfirmDialog from components/ui/Modal
       - Import showToast from components/Toast

    2. Component state:
       - showSlackModal: boolean
       - showPagerDutyModal: boolean
       - testingId: string | null (which config is being tested)
       - deleteId: string | null (which config is pending delete confirmation)

    3. Route protection:
       - Use useRequireFeature('alerting-config') at top
       - Return null if !hasAccess (redirect handled by hook)

    4. Data fetching:
       - const { data, isLoading, mutate } = useAlertConfigs()
       - Show loading skeleton while fetching

    5. Page header:
       - Title: "Alerting Settings"
       - Subtitle: "Configure Slack and PagerDuty integrations for system alerts"
       - Two buttons on right: "Add Slack" and "Add PagerDuty"
         - Add Slack: ChatBubbleLeftRightIcon, primary variant
         - Add PagerDuty: BellAlertIcon, secondary variant

    6. Main content:
       - If no configs and not loading: Show EmptyState with prompt to add first integration
       - If configs exist: Grid of AlertConfigCard components (grid-cols-1 lg:grid-cols-2)

    7. Event handlers:
       - handleToggle: async (id, enabled) => {
           try {
             if (enabled) await enableAlertConfig(id)
             else await disableAlertConfig(id)
             mutate() // refresh list
             showToast('success', enabled ? 'Integration enabled' : 'Integration disabled')
           } catch (err) {
             showToast('error', 'Failed to update integration')
           }
         }
       - handleTest: async (id) => {
           setTestingId(id)
           try {
             const result = await testAlertConfig(id)
             if (result.success) {
               showToast('success', 'Test alert sent successfully', `Response time: ${result.responseTimeMs}ms`)
             } else {
               showToast('error', 'Test alert failed', result.message)
             }
           } catch (err) {
             showToast('error', 'Failed to send test alert', err.message)
           } finally {
             setTestingId(null)
           }
         }
       - handleDelete: async () => {
           if (!deleteId) return
           try {
             await deleteAlertConfig(deleteId)
             mutate()
             showToast('success', 'Integration deleted')
           } catch (err) {
             showToast('error', 'Failed to delete integration')
           } finally {
             setDeleteId(null)
           }
         }
       - handleCreateSuccess: () => { mutate() }

    8. Include SlackConfigModal and PagerDutyConfigModal at bottom of component
       - Pass isOpen, onClose, onSuccess props

    9. Include ConfirmDialog for delete confirmation
       - isOpen={!!deleteId}
       - onClose={() => setDeleteId(null)}
       - onConfirm={handleDelete}
       - variant="danger"
       - title="Delete Integration"
       - message="Are you sure you want to delete this integration? This action cannot be undone."

    Follow existing page patterns exactly. Use consistent spacing (py-8, space-y-8).
  </action>
