    2. Add a comment above the env var explaining WHY the direct URL is used:
       ```yaml
       # Use direct PostgreSQL URI (not PgBouncer-pooled) for migrations.
       # PgBouncer transaction mode doesn't support DDL or advisory locks.
       ```

    3. Add `DATABASE_DIRECT_URL` as the env var name (instead of DATABASE_URL) to make the intent explicit in logs. The migration command will need to reference this. HOWEVER -- check that TypeORM's data-source.ts reads `DATABASE_URL`, so keep the env var name as `DATABASE_URL` but source it from the direct key. This way TypeORM picks it up without code changes.

    4. Add a `migrations.activeDeadlineSeconds` default of 900 (15 minutes) instead of 600. Production migrations on managed PostgreSQL with SSL have higher latency.

    3. Update `migrations.activeDeadlineSeconds` default to 900.
