Create PagerDutyProvider implementing AlertProvider interface:

1. Import dependencies:
   - @nestjs/common (Injectable, Logger)
   - https (Node.js native)
   - AlertProvider, AlertEvent, AlertDeliveryResult, TestAlertResult, AlertProviderType, AlertSeverity from interfaces

2. Define PagerDuty payload types (internal):
   ```typescript
   interface PagerDutyTriggerEvent {
     routing_key: string;
     event_action: 'trigger' | 'acknowledge' | 'resolve';
     dedup_key: string;
     payload: {
       summary: string;
       source: string;
       severity: 'critical' | 'error' | 'warning' | 'info';
       timestamp?: string;
       component?: string;
       group?: string;
       class?: string;
       custom_details?: Record<string, unknown>;
     };
     client?: string;
     client_url?: string;
     links?: Array<{ href: string; text: string }>;
   }
   ```

3. Class PagerDutyProvider implements AlertProvider:

   **readonly type: AlertProviderType = 'pagerduty'**

   **Private constants:**
   - EVENTS_API_URL = 'https://events.pagerduty.com/v2/enqueue'
   - REQUEST_TIMEOUT = 30000

   **send(alert: AlertEvent, config: { routingKey: string }): Promise<AlertDeliveryResult>**
   - ALERT-07: Skip if severity is 'warning' - return { success: true } (no-op, not an error)
   - Generate dedup_key using generateDedupKey()
   - Build payload using toPagerDutyPayload()
   - POST to Events API v2
   - Return { success: true/false, error?, responseTime }

   **test(config: { routingKey: string }): Promise<TestAlertResult>**
   - Create test alert with unique dedup_key: `nebuladns:test:${Date.now()}`
   - Send trigger event
   - Immediately send resolve event with same dedup_key (cleans up test incident)
   - Return { success, message: 'Test incident created and resolved', responseTimeMs }

   **validateConfig(config: Record<string, unknown>): boolean**
   - Check routingKey exists and is string
   - Check routingKey is exactly 32 characters (PagerDuty integration keys)
   - Return true/false

   **Private generateDedupKey(alert: AlertEvent): string**
   - ALERT-10: Consistent format to prevent incident explosion
   - Format: `nebuladns:${alert.source}:${alert.type}:${identifier}`
   - identifier = alert.metadata?.identifier || alert.id
   - Example: `nebuladns:policy-svc:system_health:service_down`
   - Same alert = same key = deduplicated incident

   **Private toPagerDutyPayload(alert: AlertEvent, routingKey: string, dedupKey: string): PagerDutyTriggerEvent**
   - Build Events API v2 payload:
     ```typescript
     {
       routing_key: routingKey,
       event_action: 'trigger',
       dedup_key: dedupKey,
       payload: {
         summary: alert.title.substring(0, 1024), // PD max length
         source: alert.source,
         severity: alert.severity,
         timestamp: alert.timestamp.toISOString(),
         component: 'Nebula DNS',
         class: alert.type,
         custom_details: {
           message: alert.message,
           ...alert.metadata
         }
       },
       client: 'Nebula DNS',
       client_url: process.env.APP_URL || 'https://app.nebuladns.com'
     }
     ```

   **Private httpPost(url: string, body: string): Promise<{ statusCode: number; body: string }>**
   - Use Node.js https module
   - Set Content-Type: application/json
   - Handle timeout
   - Return status code and response body
