Create three DTO files:

**alert-config.dto.ts:**
1. CreateSlackConfigDto:
   - name: string, @IsString, @MinLength(1), @MaxLength(255)
   - webhookUrl: string, @IsUrl, must start with 'https://hooks.slack.com/'
   - severityFilter?: AlertSeverity[], @IsOptional, @IsArray
   - eventTypes?: AlertEventType[], @IsOptional, @IsArray

2. CreatePagerDutyConfigDto:
   - name: string, @IsString, @MinLength(1), @MaxLength(255)
   - routingKey: string, @IsString, @MinLength(32), @MaxLength(32) (PagerDuty integration keys are 32 chars)
   - severityFilter?: AlertSeverity[], @IsOptional, @IsArray, default excludes 'warning' per ALERT-07
   - eventTypes?: AlertEventType[], @IsOptional, @IsArray

3. UpdateAlertConfigDto:
   - name?: string, @IsOptional
   - isEnabled?: boolean, @IsOptional
   - severityFilter?: AlertSeverity[], @IsOptional
   - eventTypes?: AlertEventType[], @IsOptional

4. AlertConfigResponseDto - for API responses (no encrypted data):
   - id, name, providerType, isEnabled, severityFilter, eventTypes, lastSentAt, lastError, errorCount, createdAt

**alert-event.dto.ts:**
1. AlertEventDto - internal event representation matching interface
2. CreateAlertEventDto - for manually triggering alerts (admin use)

**test-alert.dto.ts:**
1. TestAlertRequestDto: { providerType?: string } - optional, defaults to test all
2. TestAlertResponseDto: { success: boolean, message: string, responseTimeMs?: number }

Add Swagger decorators (@ApiProperty) to all DTOs.
