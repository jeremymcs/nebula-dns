<task type="auto">
  <name>Task 2: Create AlertingService with encrypted config CRUD</name>
  <files>api/src/modules/alerting/alerting.service.ts</files>
  <action>
Create AlertingService following the SIEM service pattern:

1. Import dependencies:
   - @nestjs/common (Injectable, NotFoundException, BadRequestException, Logger)
   - @nestjs/typeorm (InjectRepository)
   - typeorm (Repository)
   - AlertConfig entity
   - DTOs (CreateSlackConfigDto, CreatePagerDutyConfigDto, UpdateAlertConfigDto, AlertConfigResponseDto)
   - encrypt, decrypt, deriveKey from encryption.util
   - getEncryptionKey from encryption.config

2. Constructor:
   - Inject AlertConfig repository
   - Initialize encryption key using getEncryptionKey('ALERTING_ENCRYPTION_KEY')
   - Derive key with deriveKey(key, 'alerting-gcm-salt')

3. Private methods:
   - encryptSecret(text: string): string - uses encrypt()
   - decryptSecret(encryptedText: string): string - uses decrypt() with error handling

4. Public methods:

   **createSlack(dto: CreateSlackConfigDto): Promise<AlertConfig>**
   - Validate webhookUrl starts with 'https://hooks.slack.com/'
   - Create config with providerType: 'slack'
   - Encrypt webhookUrl into configEncrypted.webhookUrl
   - Set severityFilter and eventTypes from DTO (defaults if not provided)
   - Save and return

   **createPagerDuty(dto: CreatePagerDutyConfigDto): Promise<AlertConfig>**
   - Validate routingKey is 32 characters
   - Create config with providerType: 'pagerduty'
   - Encrypt routingKey into configEncrypted.routingKey
   - Set severityFilter excluding 'warning' by default (ALERT-07)
   - Save and return

   **findAll(): Promise<AlertConfigResponseDto[]>**
   - Find all configs
   - Map to response DTO (exclude encrypted data)
   - Order by createdAt DESC

   **findOne(id: string): Promise<AlertConfig>**
   - Find by id, throw NotFoundException if not found
   - Return full entity (for internal use)

   **findEnabled(): Promise<AlertConfig[]>**
   - Find all where isEnabled = true
   - Used by dispatcher

   **update(id: string, dto: UpdateAlertConfigDto): Promise<AlertConfig>**
   - Find config, throw if not found
   - Update allowed fields (name, isEnabled, severityFilter, eventTypes)
   - Save and return

   **enable(id: string): Promise<AlertConfig>**
   - Set isEnabled = true, reset errorCount and lastError
   - Save and return

   **disable(id: string): Promise<AlertConfig>**
   - Set isEnabled = false
   - Save and return

   **delete(id: string): Promise<void>**
   - Find config, throw if not found
   - Remove from database

   **getDecryptedConfig(id: string): Promise<{ config: AlertConfig; decrypted: Record<string, string> }>**
   - Find config
   - Decrypt all values in configEncrypted
   - Return both config and decrypted values (for providers to use)

   **updateDeliveryStatus(id: string, success: boolean, error?: string): Promise<void>**
   - Update lastSentAt, lastError, errorCount
   - If success: reset errorCount, clear lastError
   - If failure: increment errorCount, set lastError
   - Auto-disable if errorCount >= 10

5. Private helper:
   **toResponseDto(config: AlertConfig): AlertConfigResponseDto**
   - Map entity to DTO without encrypted data

Add copyright header and proper logging throughout.
