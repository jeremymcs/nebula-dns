  <files>api/src/modules/alerting/alert-dispatcher.service.ts</files>
  <action>
Create AlertDispatcherService for central alert routing:

1. Import dependencies:
   - @nestjs/common (Injectable, Logger)
   - AlertingService
   - SlackProvider
   - PagerDutyProvider
   - AlertEvent, AlertProviderType from interfaces
   - AlertConfig entity

2. Class AlertDispatcherService:

   **Constructor:**
   - Inject AlertingService
   - Inject SlackProvider
   - Inject PagerDutyProvider
   - Build provider map: { slack: slackProvider, pagerduty: pagerdutyProvider }

   **dispatch(alert: AlertEvent): Promise<void>**
   - Get enabled configs from AlertingService.findEnabled()
   - For each config:
     - Check severity filter: if config.severityFilter doesn't include alert.severity, skip
     - Check event type filter: if config.eventTypes has values and doesn't include alert.type, skip
     - Get provider from map by config.providerType
     - Get decrypted config from AlertingService.getDecryptedConfig()
     - Call provider.send(alert, decrypted)
     - Call AlertingService.updateDeliveryStatus() with result
   - Log all dispatch attempts
   - Don't throw on individual failures (continue to next config)

   **testConfig(configId: string): Promise<{ success: boolean; message: string; responseTimeMs?: number }>**
   - Get config from AlertingService.findOne()
   - Get provider from map
   - Get decrypted config
   - Call provider.test(decrypted)
   - Return result

   **Helper methods:**
   - dispatchSystemHealth(title: string, message: string, severity: AlertSeverity, identifier?: string): Promise<void>
   - dispatchBilling(title: string, message: string, severity: AlertSeverity, identifier?: string): Promise<void>
   - dispatchSecurity(title: string, message: string, severity: AlertSeverity, identifier?: string): Promise<void>

   Each helper creates AlertEvent with appropriate type and calls dispatch().

Add copyright header with proper logging.
  </action>

  <done>AlertDispatcherService routes alerts to configured channels with filtering</done>

  <name>Task 2: Create AlertingController for admin API</name>
  <files>api/src/modules/alerting/alerting.controller.ts</files>
  <action>
Create AlertingController with admin-only endpoints:

1. Decorators at class level:
   - @ApiTags('Alerting')
   - @Controller('admin/alerting')
   - @UseGuards(AdminAuthGuard, AdminRolesGuard)
   - @AdminRoles(AdminRole.SUPER_ADMIN, AdminRole.ADMIN)

2. Inject AlertingService and AlertDispatcherService

3. Endpoints:

   **POST /admin/alerting/slack**
   - @Post('slack')
   - Body: CreateSlackConfigDto
   - Returns AlertConfigResponseDto
   - Creates Slack webhook configuration

   **POST /admin/alerting/pagerduty**
   - @Post('pagerduty')
   - Body: CreatePagerDutyConfigDto
   - Returns AlertConfigResponseDto
   - Creates PagerDuty configuration

   **GET /admin/alerting**
   - @Get()
   - Returns AlertConfigResponseDto[]
   - Lists all alert configurations

   **GET /admin/alerting/:id**
   - @Get(':id')
   - @Param('id', ParseUUIDPipe)
   - Returns AlertConfigResponseDto
   - Gets single configuration

   **PATCH /admin/alerting/:id**
   - @Patch(':id')
   - Body: UpdateAlertConfigDto
   - Returns AlertConfigResponseDto
   - Updates configuration

   **POST /admin/alerting/:id/enable**
   - @Post(':id/enable')
   - @HttpCode(200)
   - Returns { message: 'Alert configuration enabled' }

   **POST /admin/alerting/:id/disable**
   - @Post(':id/disable')
   - @HttpCode(200)
   - Returns { message: 'Alert configuration disabled' }

   **POST /admin/alerting/:id/test**
   - @Post(':id/test')
   - @HttpCode(200)
   - Returns TestAlertResponseDto
   - Sends test alert to verify configuration

   **DELETE /admin/alerting/:id**
   - @Delete(':id')
   - @HttpCode(204)
   - Deletes configuration

Add Swagger decorators (@ApiOperation, @ApiResponse) to all endpoints.
