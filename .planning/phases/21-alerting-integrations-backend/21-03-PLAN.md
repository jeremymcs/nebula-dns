  <action>
Create SlackProvider implementing AlertProvider interface:

1. Import dependencies:
   - @nestjs/common (Injectable, Logger)
   - https (Node.js native)
   - AlertProvider, AlertEvent, AlertDeliveryResult, TestAlertResult, AlertProviderType from interfaces
   - AlertSeverity from interfaces

2. Define Slack payload types (internal):
   ```typescript
   interface SlackBlock {
     type: string;
     text?: { type: string; text: string; emoji?: boolean };
     elements?: Array<{ type: string; text: string }>;
   }

   interface SlackPayload {
     text: string;
     blocks?: SlackBlock[];
   }
   ```

3. Class SlackProvider implements AlertProvider:

   **readonly type: AlertProviderType = 'slack'**

   **Private constants:**
   - SEVERITY_EMOJI map: critical -> ':rotating_light:', error -> ':x:', warning -> ':warning:', info -> ':information_source:'
   - REQUEST_TIMEOUT = 30000 (30 seconds)

   **send(alert: AlertEvent, config: { webhookUrl: string }): Promise<AlertDeliveryResult>**
   - Build Slack payload using toSlackPayload()
   - POST to webhookUrl using httpPost()
   - Return { success: true } or { success: false, error: message }
   - Measure responseTime

   **test(config: { webhookUrl: string }): Promise<TestAlertResult>**
   - Create test alert event:
     - type: 'system_health'
     - severity: 'info'
     - title: 'Nebula DNS Test Alert'
     - message: 'This is a test alert from Nebula DNS. If you see this, your Slack integration is working!'
     - source: 'nebula-dns-test'
     - timestamp: new Date()
   - Send via send() method
   - Return { success, message, responseTimeMs }

   **validateConfig(config: Record<string, unknown>): boolean**
   - Check webhookUrl exists and is string
   - Check webhookUrl starts with 'https://hooks.slack.com/'
   - Return true/false

   **Private toSlackPayload(alert: AlertEvent): SlackPayload**
   - Build Block Kit message:
     ```typescript
     {
       text: `${alert.severity.toUpperCase()}: ${alert.title}`,
       blocks: [
         {
           type: 'header',
           text: { type: 'plain_text', text: `${emoji} ${alert.title}`, emoji: true }
         },
         {
           type: 'section',
           text: { type: 'mrkdwn', text: alert.message }
         },
         {
           type: 'context',
           elements: [
             { type: 'mrkdwn', text: `*Source:* ${alert.source}` },
             { type: 'mrkdwn', text: `*Time:* ${alert.timestamp.toISOString()}` },
             { type: 'mrkdwn', text: `*Type:* ${alert.type}` }
           ]
         }
       ]
     }
     ```

   **Private httpPost(url: string, body: string): Promise<{ statusCode: number; body: string }>**
   - Use Node.js https module (pattern from webhooks.service.ts)
   - Set Content-Type: application/json
   - Handle timeout (30 seconds)
   - Return status code and response body

Add copyright header. Log errors with Logger.
