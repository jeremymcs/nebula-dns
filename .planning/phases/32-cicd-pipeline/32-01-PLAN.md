  <name>Task 1: Create reusable Docker build-push workflow</name>
  <files>.github/workflows/_build-push-image.yml</files>
  <action>
Create `.github/workflows/_build-push-image.yml` as a reusable workflow (triggered by `workflow_call`).

**Inputs (all required):**
- `service` (string): Service name used for cache scoping (e.g., "api", "ui", "admin-ui")
- `context` (string): Docker build context path (e.g., "./api", "./ui")
- `registry` (string): Container registry URL (e.g., "registry.digitalocean.com/nebula-dns")
- `image_name` (string): Full image name (e.g., "nebula-dns-api")

**Secrets (required):**
- `DIGITALOCEAN_ACCESS_TOKEN`: DO API token for DOCR authentication

**Steps:**
1. `actions/checkout@v4`
2. `docker/setup-buildx-action@v3` (required for GHA cache backend)
3. `digitalocean/action-doctl@v2` with the DO token secret
4. `doctl registry login --expiry-seconds 1200` (20-min short-lived token per research pitfall #1)
5. `docker/metadata-action@v5` to extract tags:
   - `type=sha,prefix=,format=long` (immutable git SHA tag)
   - `type=raw,value=latest,enable={{is_default_branch}}` (latest only on main)
6. `docker/build-push-action@v5` with:
   - `context: ${{ inputs.context }}`
   - `push: true`
   - `tags: ${{ steps.meta.outputs.tags }}`
   - `labels: ${{ steps.meta.outputs.labels }}`
   - `cache-from: type=gha,scope=${{ inputs.service }}-build` (scoped per service per research pitfall #2)
   - `cache-to: type=gha,mode=max,scope=${{ inputs.service }}-build` (mode=max caches all layers)
   - `build-args: BUILDKIT_INLINE_CACHE=1`

Add copyright header matching project convention. Use `runs-on: ubuntu-latest`.
  </action>
