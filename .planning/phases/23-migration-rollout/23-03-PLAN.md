  <name>Task 1: Add Prometheus alerts for admin 403 rate</name>
  <files>monitoring/prometheus/rules/nebuladns-alerts.yml</files>
  <action>
Add two new alert rules to the existing nebuladns-alerts.yml file, after the existing alerts:

```yaml
      # Admin RBAC Monitoring
      - alert: Admin403RateWarning
        expr: |
          (
            sum(rate(http_requests_total{job="nebuladns-api",path=~"/admin/.*",status="403"}[5m]))
            /
            sum(rate(http_requests_total{job="nebuladns-api",path=~"/admin/.*"}[5m]))
          ) > 0.1
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "High 403 rate on admin endpoints"
          description: "Admin endpoint 403 rate is above 10% for 5 minutes. May indicate RBAC misconfiguration or legitimate access changes."

      - alert: Admin403RateCritical
        expr: |
          (
            sum(rate(http_requests_total{job="nebuladns-api",path=~"/admin/.*",status="403"}[5m]))
            /
            sum(rate(http_requests_total{job="nebuladns-api",path=~"/admin/.*"}[5m]))
          ) > 0.3
        for: 2m
        labels:
          severity: critical
        annotations:
          summary: "Critical 403 rate on admin endpoints"
          description: "Admin endpoint 403 rate is above 30% for 2 minutes. RBAC rollback may be needed. Set ADMIN_RBAC_ENABLED=false to disable."
```

These alerts:
- Warning at 10% 403 rate sustained for 5 minutes
- Critical at 30% 403 rate sustained for 2 minutes
- Use the standard http_requests_total metric with path and status labels
- Include actionable descriptions with rollback instructions
