    1. `listPaymentMethods(customerId: string): Promise<Stripe.PaymentMethod[]>`
       - Call `this.stripe.paymentMethods.list({ customer: customerId, type: 'card' })`
       - Return `paymentMethods.data` array
       - Handle errors with BadRequestException

    2. `createSetupIntent(customerId: string): Promise<{ clientSecret: string }>`
       - Call `this.stripe.setupIntents.create({ customer: customerId, payment_method_types: ['card'], usage: 'off_session' })`

       - Handle errors with BadRequestException

    3. `setDefaultPaymentMethod(customerId: string, paymentMethodId: string): Promise<void>`
       - Call `this.stripe.customers.update(customerId, { invoice_settings: { default_payment_method: paymentMethodId } })`
       - Log success
       - Handle errors with BadRequestException

    4. `detachPaymentMethod(paymentMethodId: string): Promise<void>`
       - Call `this.stripe.paymentMethods.detach(paymentMethodId)`
       - Log success
       - Handle errors with BadRequestException

    5. `getPaymentMethod(paymentMethodId: string, expectedCustomerId?: string): Promise<Stripe.PaymentMethod>`
       - Call `this.stripe.paymentMethods.retrieve(paymentMethodId)`
       - If expectedCustomerId provided, verify `pm.customer === expectedCustomerId`, throw ForbiddenException if not
       - Return payment method
       - Handle errors with BadRequestException/NotFoundException

    **AdminBillingService additions** (api/src/modules/admin/admin-billing.service.ts):

    Add four new methods following existing patterns (tenant lookup, subscription check, Stripe call, audit log):

    1. `listPaymentMethods(tenantId: string): Promise<PaymentMethodListResponseDto>`
       - Find tenant (throw NotFoundException if not found)
       - Get subscription via subscriptionsService.getSubscription(tenantId)
       - If no stripeCustomerId, return `{ data: [], total: 0 }`
       - Call paymentsService.listPaymentMethods(stripeCustomerId)
       - Get default payment method via customer's invoice_settings (use getDefaultPaymentMethod)
       - Map each Stripe.PaymentMethod to PaymentMethodDto, setting isDefault based on comparison
       - Return `{ data: mappedMethods, total: mappedMethods.length }`

    2. `createSetupIntent(tenantId: string, adminId: string): Promise<CreateSetupIntentResponseDto>`
       - Find tenant (throw NotFoundException if not found)
       - Get subscription OR create Stripe customer if none exists
       - Use paymentsService.getOrCreateCustomer(tenant.contactEmail, tenant.name) if no stripeCustomerId
       - If new customer created, update subscription record with stripeCustomerId
       - Call paymentsService.createSetupIntent(stripeCustomerId)
       - Audit log: action='billing_setup_intent_created', resourceType='subscription'
       - Return { clientSecret }

    3. `setDefaultPaymentMethod(tenantId: string, paymentMethodId: string, adminId: string): Promise<SetDefaultPaymentMethodResponseDto>`
       - Find tenant (throw NotFoundException if not found)
       - Verify billing setup (throw BadRequestException if no stripeCustomerId)
       - Verify payment method ownership via paymentsService.getPaymentMethod(paymentMethodId, stripeCustomerId)
       - Call paymentsService.setDefaultPaymentMethod(stripeCustomerId, paymentMethodId)
       - Audit log: action='billing_payment_method_default_set', include last4 and brand in newValue
       - Return { paymentMethodId, message: "Successfully set..." }

    4. `deletePaymentMethod(tenantId: string, paymentMethodId: string, adminId: string): Promise<DeletePaymentMethodResponseDto>`
       - Find tenant (throw NotFoundException if not found)
       - Verify billing setup (throw BadRequestException if no stripeCustomerId)
       - Get payment method with ownership validation
       - Check if this is default payment method - if so, throw BadRequestException("Cannot delete default payment method. Set another method as default first.")
       - List all payment methods - if count === 1, throw BadRequestException("Cannot delete the only payment method on file.")
       - Call paymentsService.detachPaymentMethod(paymentMethodId)
       - Audit log: action='billing_payment_method_deleted', include last4 and brand in oldValue
       - Return { paymentMethodId, message: "Successfully deleted..." }

    Add private helper method:
    `private mapPaymentMethod(pm: Stripe.PaymentMethod, defaultPmId: string | null): PaymentMethodDto`

    **AdminController additions** (api/src/modules/admin/admin.controller.ts):

    Add imports for new DTOs: PaymentMethodListResponseDto, CreateSetupIntentResponseDto, SetDefaultPaymentMethodDto, SetDefaultPaymentMethodResponseDto, DeletePaymentMethodResponseDto

    Add four new endpoints under "// ===== Payment Method Endpoints =====" section (after billing endpoints):

    1. `GET /admin/tenants/:tenantId/billing/payment-methods`
       - @UseGuards(AdminAuthGuard), @ApiBearerAuth('admin-jwt')
       - @ApiOperation: summary='List tenant payment methods', description='Returns all payment methods attached to tenant's Stripe customer'
       - @ApiParam: tenantId
       - @ApiResponse: 200 with PaymentMethodListResponseDto, 404 tenant not found, 401 auth required
       - Calls adminBillingService.listPaymentMethods(tenantId)

    2. `POST /admin/tenants/:tenantId/billing/payment-methods`
       - @UseGuards(AdminAuthGuard), @ApiBearerAuth('admin-jwt')
       - @ApiOperation: summary='Create SetupIntent for adding payment method', description='Returns client_secret for Stripe.js to collect card details. Payment method is auto-attached on confirmation.'
       - @ApiParam: tenantId
       - @ApiResponse: 201 with CreateSetupIntentResponseDto, 404 tenant not found, 401 auth required
       - Extract adminId from req.user
       - Calls adminBillingService.createSetupIntent(tenantId, adminId)

    3. `PATCH /admin/tenants/:tenantId/billing/payment-methods/default`
       - @UseGuards(AdminAuthGuard), @ApiBearerAuth('admin-jwt'), @HttpCode(HttpStatus.OK)
       - @ApiOperation: summary='Set default payment method', description='Sets the specified payment method as default for future invoices'
       - @ApiParam: tenantId
       - @Body: SetDefaultPaymentMethodDto
       - @ApiResponse: 200 with SetDefaultPaymentMethodResponseDto, 400 validation/ownership error, 404 not found, 401 auth required
       - Extract adminId from req.user
       - Calls adminBillingService.setDefaultPaymentMethod(tenantId, dto.paymentMethodId, adminId)

    4. `DELETE /admin/tenants/:tenantId/billing/payment-methods/:paymentMethodId`
       - @UseGuards(AdminAuthGuard), @ApiBearerAuth('admin-jwt')
       - @ApiOperation: summary='Delete payment method', description='Removes a payment method. Cannot delete default or only payment method.'
       - @ApiParam: tenantId, paymentMethodId
       - @ApiResponse: 200 with DeletePaymentMethodResponseDto, 400 cannot delete default/only, 404 not found, 401 auth required
       - Extract adminId from req.user
       - Calls adminBillingService.deletePaymentMethod(tenantId, paymentMethodId, adminId)
