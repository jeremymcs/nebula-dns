**Go code changes in `policy-svc/cmd/main.go`:**

1. Replace the plain Redis connection (lines 76-78) with `redis.ParseURL()`:
   - Currently: `redisClient := redis.NewClient(&redis.Options{Addr: redisURL})`
   - Change to: Parse with `redis.ParseURL(redisURL)`, fall back to plain `Addr` if parsing fails (backward compatible with dev `redis:6379`)
   - The `rediss://` scheme in managed Valkey URLs automatically enables TLS in go-redis ParseURL
   - Update the default `redisURL` from `"redis:6379"` to `"redis://redis:6379"` so ParseURL works for both dev and prod

2. Add `"crypto/tls"` import (needed for explicit TLS config fallback if ParseURL doesn't set MinVersion)

The exact change for the Redis connection block:

```go
redisURL := os.Getenv("REDIS_URL")
if redisURL == "" {
    redisURL = "redis://redis:6379"
}

opts, err := redis.ParseURL(redisURL)
if err != nil {
    sugar.Fatalw("Failed to parse Redis URL", "error", err, "url", redisURL)
}

// Ensure TLS 1.2+ for managed Valkey (rediss:// URLs)
if opts.TLSConfig != nil {
    opts.TLSConfig.MinVersion = tls.VersionTLS12
}

redisClient := redis.NewClient(opts)
```
