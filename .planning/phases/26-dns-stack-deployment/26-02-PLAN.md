<objective>
Create Unbound StatefulSet with persistent cache volumes, headless service for pod discovery, ClusterIP service for load-balanced access, ConfigMap for configuration, and ServiceAccount.

Purpose: Unbound is the recursive DNS resolver in the stack. StatefulSet with persistent volumes ensures DNS cache survives pod restarts (reduces upstream queries, improves latency). Headless service provides stable pod DNS for direct pod access. ClusterIP service provides load-balanced access for dnsdist.

Output: Complete Unbound K8s manifest and kustomization update.
</objective>

- Standard service account for the Unbound pods
- Labels: `app: unbound`

**3. Headless Service (unbound-headless):**
- `clusterIP: None` for headless service
- Selector: `app: unbound`
- Ports: 53 UDP (dns-udp) and 53 TCP (dns-tcp)
- Labels: `app: unbound`

**4. ClusterIP Service (unbound):**
- `type: ClusterIP`
- Selector: `app: unbound`
- Same ports as headless service
- Labels: `app: unbound`
- This is the service dnsdist will use for backend pool

**5. StatefulSet (unbound):**
- `serviceName: unbound-headless`
- `replicas: 3`
- Selector: `app: unbound`
- Pod template:
  - `serviceAccountName: unbound`
  - Pod securityContext: `runAsNonRoot: true`, `runAsUser: 100` (unbound user in Alpine), `fsGroup: 100`
  - Container: `unbound`
    - Image: `ghcr.io/nebuladns/unbound:latest`
    - `imagePullPolicy: Always`
    - Ports: 53 UDP (dns-udp), 53 TCP (dns-tcp)
    - Volume mounts:
      - `cache` at `/var/lib/unbound` (from volumeClaimTemplate)
      - `config` at `/etc/unbound/unbound.conf` with `subPath: unbound.conf`, `readOnly: true`
    - Resources:
      - requests: cpu 250m, memory 256Mi
      - limits: cpu 2, memory 2Gi
    - livenessProbe: exec `drill @127.0.0.1 google.com`, initialDelay 10s, period 30s, timeout 5s, failureThreshold 3
    - readinessProbe: exec `drill @127.0.0.1 google.com`, initialDelay 5s, period 10s, timeout 3s, failureThreshold 3
    - Container securityContext: `allowPrivilegeEscalation: false`, `readOnlyRootFilesystem: false` (Unbound writes cache), capabilities drop ALL
  - Volumes:
    - `config` from ConfigMap `unbound-config`
  - Pod anti-affinity (preferred, weight 100): spread across nodes by `kubernetes.io/hostname`
  - Prometheus annotations: `prometheus.io/scrape: "false"` (Unbound doesn't expose Prometheus metrics natively)
- volumeClaimTemplates:
  - name: `cache`
  - accessModes: `ReadWriteOnce`
  - resources.requests.storage: `1Gi`
  - labels: `app: unbound`

**6. PodDisruptionBudget (unbound-pdb):**
- `minAvailable: 2`
- Selector: `app: unbound`
