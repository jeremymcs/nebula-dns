  <action>
Create four modal components for billing actions per CONTEXT.md.

**ApplyCreditModal props and implementation:**
- Props: `isOpen, onClose, tenantId, tenantName, onSuccess`
- Fields: Amount (number input in dollars, convert to cents), Reason (textarea, required)
- Note per CONTEXT.md: optional expiry date, but backend doesn't support it yet - skip for now
- Submit: POST /admin/tenants/:tenantId/billing/credits with { amountCents, reason }
- Show confirmation before submitting: "Apply $X credit to [tenantName]?"
- On success: call onSuccess(), close modal, amount and reason fields reset

**ChangeTierModal props and implementation:**
- Props: `isOpen, onClose, tenantId, tenantName, currentTier, onSuccess`
- Layout: Side-by-side comparison per CONTEXT.md
- Left column: Current tier with features
- Right column: Select new tier dropdown + features for selected tier
- Feature list (hardcoded per research recommendation):
  - Home: Basic DNS filtering, 1 location, Family sharing
  - Enterprise: Advanced filtering, Unlimited locations, API access, SSO
  - MSP: All Enterprise + Multi-tenant management, Client billing, Templates
- Timing: Radio buttons for "Immediate" or "End of billing period"
- Reason: Required textarea
- Submit: POST /admin/tenants/:tenantId/billing/tier with { newTier, timing, reason }
- Disable submit if newTier === currentTier

**ExtendTrialModal props and implementation:**
- Props: `isOpen, onClose, tenantId, tenantName, currentTrialEnd, onSuccess`
- Fields: Days to extend (number, 1-30), Reason (required), Notify tenant (checkbox)
- Show current trial end date and preview of new end date
- Submit: POST /admin/tenants/:tenantId/billing/trial/extend with { days, reason, notifyTenant }

**ExtendGraceModal props and implementation:**
- Props: `isOpen, onClose, tenantId, tenantName, currentGraceEnd, daysRemaining, onSuccess`
- Fields: Days to extend (number, 1-14), Reason (required), Notify tenant (checkbox)
- Show current grace period info and preview of new end date
- Submit: POST /admin/tenants/:tenantId/billing/grace/extend with { days, reason, notifyTenant }

**Common patterns for all modals:**
- Use Modal component from @/components/ui/Modal
- Use Button component with isLoading state
- Show error message below form if submission fails
- Disable submit button during loading
- Use adminBillingRequest from useAdminBilling.ts for API calls
- Add copyright headers to all files
