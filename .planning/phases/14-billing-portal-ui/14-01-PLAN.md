Create the billing portal page at `/mission-control/tenants/[id]/billing`.

**Page structure:**
1. Breadcrumb: Mission Control > MSPs > [Tenant Name] > Billing
2. Page header: Tenant name with ID subtitle
3. Alert banner (conditional): Red alert for suspended, amber for past_due/grace period
4. Stat cards grid (4 columns on lg):
   - Current Tier (with Change Tier button - placeholder onClick)
   - Status (color-coded badge)
   - Billing Cycle (monthly/yearly)
   - Credit Balance (formatted as currency, with Add Credit button - placeholder onClick)
5. Additional date info row (3 columns):
   - Current Period End
   - Trial End (if applicable)
   - Grace Period End (if applicable)

**Alert banner logic:**
- status === 'canceled' or suspended state: Red bg-danger-100 with ExclamationTriangleIcon
- status === 'past_due' or gracePeriod exists: Amber bg-warning-100 with ExclamationTriangleIcon
- Otherwise no banner

**Loading states:**
- Use Skeleton components for cards during load
- Show "Loading billing information..." text

**Error states:**
- Show error card with retry suggestion
- Handle case where tenant has no Stripe customer (stripeCustomerId: null)

**Empty state for no billing:**
- If no stripeCustomerId, show helpful message: "No billing configured for this tenant"

Use Card, Badge, Skeleton from @/components/ui. Use StatCard pattern from MSP detail page.
Match existing page styles (max-w-[1600px], px-4 sm:px-6 lg:px-8, py-8).
