  <files>ui/src/components/billing/AddPaymentMethodModal.tsx</files>
  <action>
Create modal with embedded Stripe PaymentElement for secure card collection.

**Component props:**
- `isOpen: boolean`
- `onClose: () => void`
- `tenantId: string`
- `tenantName: string`
- `onSuccess: () => void`

**Flow (per research SetupIntent pattern):**
1. When modal opens, call POST /admin/tenants/:tenantId/billing/payment-methods to get clientSecret
2. Render Elements provider with clientSecret
3. User fills in PaymentElement form
4. On submit, call stripe.confirmSetup({ elements, redirect: 'if_required' })
5. On success, call onSuccess and close modal
6. On error, display error message in modal

**Component structure:**
```tsx
function AddPaymentMethodModal({ isOpen, onClose, tenantId, tenantName, onSuccess }) {
  const [clientSecret, setClientSecret] = useState<string | null>(null)
  const [error, setError] = useState<string | null>(null)
  const [isLoadingSecret, setIsLoadingSecret] = useState(false)

  // Fetch clientSecret when modal opens
  useEffect(() => {
    if (isOpen && !clientSecret) {
      fetchSetupIntent()
    }
  }, [isOpen])

  // Reset state when modal closes
  useEffect(() => {
    if (!isOpen) {
      setClientSecret(null)
      setError(null)
    }
  }, [isOpen])

  return (
    <Modal isOpen={isOpen} onClose={onClose} title="Add Payment Method" size="md">
      {isLoadingSecret && <Loading />}
      {error && !clientSecret && <ErrorMessage />}
      {clientSecret && (
        <Elements stripe={stripePromise} options={{ clientSecret }}>
          <PaymentForm tenantName={tenantName} onSuccess={handleSuccess} onError={setError} />
        </Elements>
      )}
    </Modal>
  )
}
```

**PaymentForm inner component:**
- Uses useStripe() and useElements() hooks
- Renders PaymentElement component
- Submit button: "Add Payment Method"
- Handles confirmSetup with redirect: 'if_required'
- Shows inline error if confirmation fails

**Error handling:**
- If Stripe not loaded: "Payment system unavailable"
- If SetupIntent creation fails: show backend error message
- If card validation fails: Stripe shows inline errors
- If confirmation fails: show Stripe error message

**Styling:**
- PaymentElement uses default Stripe styling (acceptable)
- Modal padding around the element
- Submit button with loading state
