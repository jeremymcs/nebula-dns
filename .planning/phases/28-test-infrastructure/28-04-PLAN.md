  <files>
    scripts/k8s/create-ephemeral-namespace.sh
    scripts/k8s/cleanup-ephemeral-namespaces.sh
  </files>
  <action>
    Create `scripts/k8s/` directory.

    **scripts/k8s/create-ephemeral-namespace.sh**:
    - Copyright header comment
    - `set -e` for fail-fast
    - Accept arguments: `$1` = identifier (PR number or run ID), `$2` = optional TTL in hours (default 4)
    - Generate namespace name: `nebula-test-${1}-$(date +%s)` (truncated to 63 chars for K8s limit)
    - `kubectl create namespace "$NAMESPACE"`
    - Label namespace with:
      - `ephemeral=true`
      - `identifier=$1`
      - `created-at=$(date +%s)`
      - `ttl-hours=$TTL`
    - Apply ResourceQuota:
      - requests.cpu: "4"
      - requests.memory: 8Gi
      - limits.cpu: "8"
      - limits.memory: 16Gi
      - persistentvolumeclaims: "5"
      - services.loadbalancers: "0" (no external LBs for test envs)
    - Apply LimitRange for default container limits:
      - default: cpu 500m, memory 512Mi
      - defaultRequest: cpu 100m, memory 128Mi
    - Output namespace name to stdout (last line) for CI capture
    - Also output via GitHub Actions format: `echo "namespace=$NAMESPACE" >> $GITHUB_OUTPUT` if `$GITHUB_OUTPUT` is set
    - Make executable

    **scripts/k8s/cleanup-ephemeral-namespaces.sh**:
    - Copyright header comment
    - `set -e` for fail-fast
    - Accept `$1` = optional max age in hours (default 4)
    - Calculate max age in seconds
    - `kubectl get namespaces -l ephemeral=true -o json`
    - Parse with `jq` to get namespace name and created-at label
    - For each namespace: if age > max age, delete it with `kubectl delete namespace "$ns" --wait=false`
    - Print summary: deleted count and remaining count
    - Accept `--dry-run` flag to show what would be deleted without deleting
    - Make executable
  </action>

    `bash -n scripts/k8s/create-ephemeral-namespace.sh` passes syntax check.
    `bash -n scripts/k8s/cleanup-ephemeral-namespaces.sh` passes syntax check.
    Both files are executable.
  </verify>
  <done>Namespace creation script generates unique names with resource quotas and labels. Cleanup script removes stale namespaces based on TTL. Both support CI integration.</done>
