  <action>
    Add a new `ui-e2e-test` job to `.github/workflows/ci.yml` after the existing `ui-test` job. This job runs Playwright E2E tests.

    ```yaml
    # UI E2E Tests
    ui-e2e-test:
      name: UI E2E Tests
      runs-on: ubuntu-latest
      needs: [ui-test]

      steps:
        - name: Checkout code
          uses: actions/checkout@v4

        - name: Setup Node.js
          uses: actions/setup-node@v4
          with:
            node-version: ${{ env.NODE_VERSION }}
            cache: 'npm'
            cache-dependency-path: ui/package-lock.json

        - name: Install dependencies
          working-directory: ./ui
          run: npm ci --legacy-peer-deps

        - name: Install Playwright browsers
          working-directory: ./ui
          run: npx playwright install --with-deps chromium

        - name: Run E2E tests
          working-directory: ./ui
          run: npx playwright test --project=chromium
          env:
            CI: true
            TEST_BASE_URL: http://localhost:4011

        - name: Upload Playwright report
          uses: actions/upload-artifact@v4
          if: always()
          with:
            name: playwright-report
            path: ui/playwright-report/
            retention-days: 14

        - name: Upload test results
          uses: actions/upload-artifact@v4
          if: failure()
          with:
            name: playwright-test-results
            path: ui/test-results/
            retention-days: 7
    ```

    Key decisions:
    - Install only `chromium` in CI (not all browsers) to save CI time. WebKit and Firefox run locally.
    - `needs: [ui-test]` — E2E only runs after build/lint/typecheck passes
    - Use `actions/upload-artifact@v4` (not deprecated v3)
    - Upload report always, test results (traces/videos) only on failure
    - Do NOT add to the `build` job `needs` array — E2E tests are informational, not blocking Docker builds (yet)

    Also update the existing `build` job `needs` to NOT depend on `ui-e2e-test` to avoid blocking the build pipeline initially.
  </action>
