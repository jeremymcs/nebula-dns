  <action>
Create monitoring/grafana/dashboards/slo-dashboard.json as a complete Grafana dashboard JSON with these panels organized in rows:

**Row 1: SLO Overview (4 stat panels, single-stat gauges)**

Panel 1 - "DNS Availability (30d)":
- Type: stat
- PromQL: `avg(avg_over_time(probe_success{job="blackbox-dns"}[30d])) * 100`
- Unit: percent (0-100)
- Thresholds: green >99.9, yellow >99.5, red <99.5
- Description: "SLO Target: 99.9%"

Panel 2 - "Error Budget Remaining":
- Type: gauge
- PromQL: `((0.001 - (1 - avg(avg_over_time(probe_success{job="blackbox-dns"}[30d])))) / 0.001) * 100`
- Unit: percent (0-100)
- Thresholds: green >75, yellow >25, orange >0, red <=0
- Description: "Error budget: 43.8 minutes/month"

Panel 3 - "API p95 Latency":
- Type: stat
- PromQL: `histogram_quantile(0.95, sum(rate(http_request_duration_seconds_bucket{job="api"}[5m])) by (le)) * 1000`
- Unit: ms
- Thresholds: green <180, yellow <200, red >=200
- Description: "SLO Target: <200ms"

Panel 4 - "Policy Eval p95 Latency":
- Type: stat
- PromQL: `histogram_quantile(0.95, sum(rate(policy_evaluation_duration_seconds_bucket{job="policy-svc"}[5m])) by (le)) * 1000`
- Unit: ms
- Thresholds: green <45, yellow <50, red >=50
- Description: "SLO Target: <50ms"

**Row 2: Availability Over Time (2 time-series panels)**

Panel 5 - "DNS Availability (1h windows)":
- Type: timeseries
- PromQL: `avg(avg_over_time(probe_success{job="blackbox-dns"}[1h])) * 100`
- SLO target line at 99.9% (annotation or threshold)
- Time range: 7d default

Panel 6 - "Error Budget Burn Rate":
- Type: timeseries
- PromQL fast burn: `(1 - avg(avg_over_time(probe_success{job="blackbox-dns"}[1h]))) / 0.001`
- PromQL slow burn: `(1 - avg(avg_over_time(probe_success{job="blackbox-dns"}[6h]))) / 0.001`
- Horizontal lines at burn rate 14.4 (critical) and 6 (warning)
- Y-axis label: "Burn Rate (1.0 = sustainable)"

**Row 3: Latency Trends (2 time-series panels)**

Panel 7 - "API Latency Distribution":
- Type: timeseries
- PromQL lines for p50, p95, p99: `histogram_quantile(0.{50,95,99}, sum(rate(http_request_duration_seconds_bucket{job="api"}[5m])) by (le)) * 1000`
- SLO threshold line at 200ms
- Unit: ms

Panel 8 - "Policy Eval Latency Distribution":
- Type: timeseries
- PromQL lines for p50, p95, p99: `histogram_quantile(0.{50,95,99}, sum(rate(policy_evaluation_duration_seconds_bucket{job="policy-svc"}[5m])) by (le)) * 1000`
- SLO threshold line at 50ms
- Unit: ms

**Row 4: Probe Details (2 panels)**

Panel 9 - "Probe Success by Type":
- Type: timeseries
- PromQL: `avg(probe_success{job="blackbox-dns"}) by (probe_type)`
- Legend: dns_udp, doh_https

Panel 10 - "Probe Duration by Type":
- Type: timeseries
- PromQL: `avg(probe_duration_seconds{job="blackbox-dns"}) by (probe_type) * 1000`
- Unit: ms

Dashboard settings:
- Title: "Nebula DNS - SLO Tracking"
- UID: "nebula-dns-slo"
- Tags: ["nebula-dns", "slo", "availability"]
- Refresh: 30s
- Time range: 24h default
- Datasource variable: `${DS_PROMETHEUS}` (templated)
- Annotations: Show active SLO alerts

Copy the same JSON to k8s/base/monitoring/grafana-slo-dashboard.json for Kubernetes deployment.
