- Add GitHub Step Summary output after each test job:
  ```yaml
  - name: Generate test summary
    if: always()
    run: |
      echo "## API Load Test Results" >> $GITHUB_STEP_SUMMARY
      echo "" >> $GITHUB_STEP_SUMMARY
      if [ -f api-results.json ]; then
        echo '```' >> $GITHUB_STEP_SUMMARY
        jq -r '.metrics.http_req_duration.values | "p95: \(.["p(95)"])ms | p99: \(.["p(99)"])ms"' api-results.json >> $GITHUB_STEP_SUMMARY 2>/dev/null || echo "Could not parse results" >> $GITHUB_STEP_SUMMARY
        echo '```' >> $GITHUB_STEP_SUMMARY
      fi
  ```
- Add pass/fail status based on k6 exit code (remove `continue-on-error: true` for scheduled runs, keep for manual dispatch)
