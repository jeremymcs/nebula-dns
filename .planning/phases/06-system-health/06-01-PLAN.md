<task type="auto">
  <name>Task 2: Create AdminHealthService</name>
  <files>api/src/modules/admin/admin-health.service.ts</files>
  <action>
Create admin-health.service.ts with health aggregation logic:

**Constructor dependencies:**
- ConfigService (for service URLs)
- ClickHouseService (for error rates and query volume)
- RedisService (for connection status)
- HealthService (for existing postgres/redis/clickhouse checks)
- HttpService from @nestjs/axios (for external service probes)

**Service URL configuration:**
Read from ConfigService with defaults:
- POLICY_SVC_URL: 'http://policy-svc:8080' (internal docker network)
- DNSDIST_URL: 'http://dnsdist:8083' (webserver port)
- UNBOUND_HOST: 'unbound' (for DNS query check)

**Methods:**

1. **getSystemHealth(): Promise<SystemHealthResponseDto>**
   - Call all check methods in parallel using Promise.all()
   - Compute overallStatus: healthy if all healthy, unhealthy if any critical service down, degraded otherwise
   - Return combined SystemHealthResponseDto

2. **checkPolicySvc(): Promise<ServiceStatusDto>**
   - HTTP GET to ${POLICY_SVC_URL}/health with 5s timeout
   - Catch errors and return unhealthy status with error message
   - Measure latencyMs

3. **checkDnsdist(): Promise<ServiceStatusDto>**
   - HTTP GET to ${DNSDIST_URL}/ with 5s timeout
   - dnsdist webserver returns stats page, any 200 = healthy
   - Catch errors and return unhealthy

4. **checkUnbound(): Promise<ServiceStatusDto>**
   - Since remote-control is disabled, use a simple approach:
   - Check if DNS resolution works by attempting to resolve a known domain
   - Use dns.promises.resolve from Node.js with custom resolver pointing to unbound
   - 5s timeout, return healthy/unhealthy based on resolution success

5. **getStorageStatus(): Promise<StorageStatusDto>**
   - Redis: Use redisService.getClient().ping() with timing
   - ClickHouse: Use clickhouseService.getConnectionStatus()
   - Return combined status

6. **getErrorRates(): Promise<ErrorRatesDto>**
   - Query ClickHouse for error counts in last 1h and 24h
   - Error definition: reason LIKE '%error%' OR reason = 'policy_error'
   - Use safeQuery pattern with mock fallback
   - SQL pattern:
     ```sql
     SELECT
       count() as total,
       countIf(reason LIKE '%error%' OR reason = 'policy_error') as errors
     FROM nebula_dns.query_logs
     WHERE timestamp >= now() - INTERVAL {1 HOUR | 24 HOUR}
     ```

7. **getQueryVolume(period: '1h' | '24h' = '24h'): Promise<QueryVolumeDto>**
   - Query ClickHouse for aggregate counts across ALL tenants
   - No tenant_id filter (admin sees global)
   - Return total, blocked, allowed counts

8. **getRecentErrors(limit: number = 20): Promise<RecentErrorDto[]>**
   - Query ClickHouse for recent error entries
   - Filter: reason LIKE '%error%' OR reason = 'policy_error'
   - Order by timestamp DESC, limit to `limit`

**Error handling:**
- Each check wrapped in try-catch
- Use Promise.allSettled for parallel calls to avoid one failure stopping others
- Log errors but don't expose internal details in responses

Include copyright header. Follow admin.service.ts patterns for logging.
