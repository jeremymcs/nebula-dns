   - Import Tenant from '../../tenants/entities/tenant.entity'

2. Update admin.service.ts:
   - Add @InjectRepository(Tenant) private readonly tenantRepository: Repository<Tenant> to constructor
   - Import Repository from 'typeorm', Tenant from '../tenants/entities/tenant.entity'
   - Import the new DTOs from './dto/tenant-search.dto'

   Add private detectQueryType(query: string): 'id' | 'email' | 'name' method:
   - UUID v4 regex: /^[0-9a-f]{8}-[0-9a-f]{4}-4[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/i
   - Email regex: /^[^\s@]+@[^\s@]+\.[^\s@]+$/
   - Return 'id' if UUID, 'email' if email, otherwise 'name'

   Add private toSearchResult(tenant, matchedEmail?) helper to map to TenantSearchResultDto.

   Add async searchTenants(query: TenantSearchQueryDto): Promise<TenantSearchResponseDto>:
   - Parse query.q.trim() and detect type
   - For 'id' type: Direct findOne lookup by id, return single result or empty array
   - For 'email' type: Query builder with leftJoin('tenant.users', 'user'), where LOWER(user.email) = :email
   - For 'name' type: Query builder with ILIKE search: tenant.name ILIKE :search with %term%
   - For email/name: Get total count, then fetch with orderBy('tenant.name', 'ASC'), skip(offset), take(limit+1)
   - Compute hasMore from results.length === limit (for email/name) or false (for id)
   - Return TenantSearchResponseDto with data, pagination: { cursor, hasMore, total }

3. Update admin.controller.ts:
   - Import TenantSearchQueryDto, TenantSearchResponseDto from './dto/tenant-search.dto'
   - Add new endpoint before the logout endpoint:

   @Get('tenants/search')
   @UseGuards(AdminAuthGuard)
   @ApiBearerAuth('admin-jwt')
   @ApiOperation({ summary: 'Search tenants', description: 'Search tenants by ID, email, or name. Auto-detects query type.' })
   @ApiResponse({ status: 200, type: TenantSearchResponseDto })
   @ApiResponse({ status: 400, description: 'Query too short or invalid' })
   @ApiResponse({ status: 401, description: 'Admin authentication required' })
   async searchTenants(@Query() query: TenantSearchQueryDto): Promise<TenantSearchResponseDto> {
     return this.adminService.searchTenants(query);
   }

Key implementation notes:
- Always use parameterized queries (never interpolate user input into SQL)
- Use LOWER() for email comparison to handle case-insensitivity
- Select only needed fields: id, name, status, tier (and user.email for email search)
- Offset-based cursor: parse cursor as number (parseInt), encode as string
