<task type="auto">
  <name>Task 1: Add trial and grace extension methods to AdminBillingService</name>
  <files>api/src/modules/admin/admin-billing.service.ts, api/src/modules/admin/admin-billing.service.spec.ts</files>
  <action>
1. Add to AdminBillingService:

   a) extendTrial(tenantId, dto: ExtendTrialDto, adminId):
      - Find tenant (throw NotFoundException)
      - Get trial status via trialsService.getTrialStatus()
      - If !hasActiveTrial: throw BadRequestException('Tenant does not have an active trial')
      - Get subscription and verify stripeSubscriptionId exists
      - Call paymentsService.extendTrialPeriod(stripeSubscriptionId, dto.days)
      - Calculate newEndDate from updated subscription.trial_end
      - If dto.notifyTenant: send email via emailService (create helper method sendTrialExtensionEmail)
      - Audit log with action 'billing_trial_extended', include adminId, daysAdded, reason, previousEnd, newEnd
      - Return ExtensionResponseDto

   b) extendGracePeriod(tenantId, dto: ExtendGracePeriodDto, adminId):
      - Find tenant (throw NotFoundException)
      - Get grace info via subscriptionLapseService.getGracePeriodInfo()
      - If subscriptionStatus !== 'grace': throw BadRequestException('Tenant is not in grace period')
      - Call subscriptionLapseService.extendGracePeriod(tenantId, dto.days, adminId)
      - Calculate newEndDate based on grace period extension
      - If dto.notifyTenant: send email via emailService (create helper method sendGraceExtensionEmail)
      - Audit log with action 'billing_grace_extended', include adminId, daysAdded, reason
      - Return ExtensionResponseDto

   c) Private helper: sendTrialExtensionEmail(tenant, originalEndDate, newEndDate, daysAdded):
      - Create HTML email template informing tenant of extension
      - Include tenant name, days added, new end date
      - Use emailService generic send method or add to EmailService
      - Log if email fails but don't throw

   d) Private helper: sendGraceExtensionEmail(tenant, daysAdded, newEndDate):
      - Create HTML email template informing tenant of grace period extension
      - Include tenant name, days added, new end date, prompt to update payment
      - Log if email fails but don't throw

2. Add unit tests:
   - Test extendTrial success with notification sent
   - Test extendTrial success without notification
   - Test extendTrial throws for tenant without active trial
   - Test extendGracePeriod success with notification
   - Test extendGracePeriod success without notification
   - Test extendGracePeriod throws for tenant not in grace period
   - Test audit logging for both methods
  </action>
  <verify>npm test -- --testPathPattern="admin-billing.service" passes all tests</verify>
  <done>AdminBillingService has extendTrial and extendGracePeriod methods with optional notification and audit logging</done>
</task>
