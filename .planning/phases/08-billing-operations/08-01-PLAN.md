<task type="auto">
  <name>Task 2: Extend PaymentsService with Stripe operations</name>
  <files>api/src/modules/payments/payments.service.ts</files>
  <action>
Add new methods to existing PaymentsService for admin billing operations:

1. listInvoices(customerId, options):
   - Parameters: customerId (string), options: { limit?: number, startingAfter?: string }
   - Fetch invoices from Stripe with limit + 1 pattern for hasMore detection
   - Return: { invoices: Stripe.Invoice[], hasMore: boolean }

2. getInvoicePdfWithValidation(invoiceId, expectedCustomerId):
   - Retrieve invoice from Stripe
   - Verify invoice.customer === expectedCustomerId (throw ForbiddenException if not)
   - Check invoice.invoice_pdf exists (throw NotFoundException if not)
   - Return: { url: string, invoice: Stripe.Invoice }

3. getDefaultPaymentMethod(customerId):
   - Retrieve customer from Stripe
   - Get invoice_settings.default_payment_method
   - Return PaymentMethod or null
   - Handle deleted customers gracefully

4. applyCredit(customerId, amountCents, description, metadata):
   - Create customer balance transaction via stripe.customers.createBalanceTransaction
   - Amount MUST be negated (-Math.abs(amountCents)) for credit
   - Include currency: 'usd', description, metadata
   - Return: Stripe.CustomerBalanceTransaction

5. changeSubscriptionPlan(subscriptionId, newPriceId, timing):
   - Retrieve subscription, get first item ID
   - Update with items array containing new price
   - proration_behavior: timing === 'immediate' ? 'always_invoice' : 'none'
   - Return updated Stripe.Subscription

6. extendTrialPeriod(subscriptionId, additionalDays):
   - Retrieve subscription
   - Verify status === 'trialing' (throw BadRequestException if not)
   - Calculate new trial_end (current + additionalDays in seconds)
   - Validate doesn't exceed 730 days total
   - Update subscription with new trial_end
   - Return updated Stripe.Subscription

All methods should check `if (!this.stripe)` and throw BadRequestException('Payment system not configured').
  </action>
