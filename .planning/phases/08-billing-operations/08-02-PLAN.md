  <name>Task 1: Add billing audit action types and credit/tier methods</name>
  <files>api/src/modules/audit-logs/entities/audit-log.entity.ts, api/src/modules/admin/admin-billing.service.ts, api/src/modules/admin/admin-billing.service.spec.ts</files>

1. Update audit-log.entity.ts AuditAction type union:
   Add: 'billing_credit_applied' | 'billing_tier_changed' | 'billing_trial_extended' | 'billing_grace_extended'

2. Add to AdminBillingService:

   a) Constants at top of class:
      - CREDIT_WARNING_THRESHOLD = 50000 (cents = $500)
      - TIER_PRICE_MAP: Record of tier -> { monthly: string, yearly: string } using env vars

   b) applyCredit(tenantId, dto: ApplyCreditDto, adminId):
      - Find tenant (throw NotFoundException)
      - Get subscription (throw BadRequestException if no stripeCustomerId)
      - If amountCents > CREDIT_WARNING_THRESHOLD: log warning but proceed
      - Call paymentsService.applyCredit()
      - Audit log with action 'billing_credit_applied', include adminId, transactionId, newBalance
      - Return CreditAppliedResponseDto with formatted message

   c) changeTier(tenantId, dto: ChangeTierDto, adminId):
      - Find tenant (throw NotFoundException)
      - Get subscription (throw BadRequestException if no stripeSubscriptionId)
      - Determine newPriceId from TIER_PRICE_MAP based on billingCycle
      - Call paymentsService.changeSubscriptionPlan()
      - Update tenant.tier in database
      - If timing === 'immediate': update subscription.planId immediately
      - Audit log with action 'billing_tier_changed', include previousTier, newTier, timing, adminId
      - Return TierChangeResponseDto with effectiveAt

3. Add unit tests to admin-billing.service.spec.ts:
   - Test applyCredit success with audit logging
   - Test applyCredit logs warning for large credits
   - Test applyCredit throws for tenant without billing
   - Test changeTier success with immediate timing
   - Test changeTier success with end_of_period timing
   - Test changeTier throws for missing subscription
  </action>
  <verify>npm test -- --testPathPattern="admin-billing.service" passes all tests</verify>
  <done>AdminBillingService has applyCredit and changeTier methods with audit logging and tests</done>

2. Update AdminController:
   - Inject AdminBillingService in constructor
   - Import Response from 'express' and @Res decorator

3. Add billing endpoints (all protected by AdminAuthGuard):

   a) GET /admin/tenants/:tenantId/billing/subscription
      - @ApiOperation: 'Get tenant subscription status'
      - @ApiParam: tenantId (UUID)
      - @ApiResponse: 200 with SubscriptionStatusResponseDto, 404 Tenant not found
      - Call adminBillingService.getSubscriptionStatus(tenantId)

   b) GET /admin/tenants/:tenantId/billing/invoices
      - @ApiOperation: 'List tenant invoices'
      - @ApiParam: tenantId (UUID)
      - @Query: InvoiceListQueryDto
      - @ApiResponse: 200 with InvoiceListResponseDto, 404 Tenant not found
      - Call adminBillingService.listInvoices(tenantId, query)

   c) GET /admin/tenants/:tenantId/billing/invoices/:invoiceId/pdf
      - @ApiOperation: 'Download invoice PDF'
      - @ApiParam: tenantId, invoiceId
      - @ApiResponse: 200 with PDF stream, 404 Invoice not found
      - @Res() res: Response
      - Call adminBillingService.streamInvoicePdf(tenantId, invoiceId, res)

   d) POST /admin/tenants/:tenantId/billing/credits
      - @ApiOperation: 'Apply credit to tenant account'
      - @ApiParam: tenantId (UUID)
      - @Body: ApplyCreditDto
      - @ApiResponse: 201 with CreditAppliedResponseDto, 400 Validation, 404 Tenant not found
      - Extract adminId from req.user
      - Call adminBillingService.applyCredit(tenantId, dto, adminId)

   e) POST /admin/tenants/:tenantId/billing/tier
      - @ApiOperation: 'Change tenant subscription tier'
      - @ApiParam: tenantId (UUID)
      - @Body: ChangeTierDto
      - @ApiResponse: 200 with TierChangeResponseDto, 400 Validation, 404 Tenant not found

      - Call adminBillingService.changeTier(tenantId, dto, adminId)
